Lesson · Module 13

Protection

Read this in full before attempting the scenarios below — they assume this material.

Discrimination as the thing that contains a fault

Discrimination, or selectivity, between protective devices is what determines whether a fault takes down one final circuit or cascades up through an entire board. The principle — the downstream device should clear a fault before the upstream device operates — is one every SAP already knows. What's different in a data centre is how many more layers, and how much more variability in available fault current, the discrimination study has to account for.

Fault current isn't a fixed number

Available fault current at any given point in the network changes depending on running configuration — the fault current available on UPS output is meaningfully different from what's available on raw mains bypass. A discrimination study that was valid for one running state isn't automatically valid for the other. This is easy to overlook because the physical switchgear and settings haven't changed — only the running configuration has.

Why a locally correct change can break selectivity elsewhere

Changing a single device's settings — for example, upsizing a final circuit breaker to reduce nuisance tripping from IT inrush current — can look like a clean, isolated fix while quietly breaking the coordination between that device and everything else on the same distribution chain. Any protection change needs to be checked against the whole chain it sits within, not just judged on whether it solves the immediate problem.

Total versus partial selectivity, and why the distinction is practical, not academic

Total selectivity means a downstream device will clear any fault up to its full rated capacity before the upstream device operates. Partial selectivity means this is only guaranteed up to a certain fault level, above which both devices may operate together. Which one a specific board actually achieves has to be read from its real discrimination study — it cannot be assumed from the type of device installed.
