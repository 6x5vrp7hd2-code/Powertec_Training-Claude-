The problem this programme solves

The conventional route is roughly: an experienced AP/SAP arrives, shadows authorised personnel, picks up systems piecemeal, asks questions when somebody has time, gradually develops familiarity, and eventually somebody judges them ready for assessment.

That can work — but it depends entirely on the trainee, on mentor availability, and on what work happens to occur during the period. Time served should not equal competence.

This programme instead runs: baseline assessment → structured system learning → guided shadowing → practical exposure → progressive knowledge checks → scenario exercises → evidence portfolio → mock assessment → authorisation assessment.

A defined pathway, not simply accumulating time on site.

The overlay method

Rather than handing a trainee a complete single-line diagram containing everything and expecting them to absorb it, the network is reconstructed progressively — overlay by overlay, from HV intake through to the complete system. Every trainee produces their own simplified system drawings as evidence. That tests understanding, not memory.
