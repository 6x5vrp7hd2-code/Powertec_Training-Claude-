Scenario

Describe the correct breaker sequencing between the load bank, the building load, and the generator for a planned test, and what would happen if this sequence were reversed.

Model Answer

Typically the load bank is connected and its breaker closed first, then the source breaker is closed to apply load, with the building load breaker kept open throughout the test. Reversing this risks paralleling the load bank with live building load unintentionally, or applying load before the source is stable.

This is a model answer, not the only acceptable one — if your reasoning reaches the same operational conclusion by a different route, discuss it with a mentor rather than treating this as the sole correct wording.
