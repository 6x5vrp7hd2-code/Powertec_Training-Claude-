Scenario

Explain, for one bus-tie/incomer interlocking scheme, the specific dangerous busbar configuration it is designed to make physically impossible.

Model Answer

Typically the interlock prevents both incomers and the bus-tie being closed simultaneously without deliberate intent, which would parallel two separate sources onto a common bus — if those sources are out of synchronism, this drives a large circulating fault current. The interlock physically enforces that only a safe combination of positions can be achieved.

This is a model answer, not the only acceptable one — if your reasoning reaches the same operational conclusion by a different route, discuss it with a mentor rather than treating this as the sole correct wording.
