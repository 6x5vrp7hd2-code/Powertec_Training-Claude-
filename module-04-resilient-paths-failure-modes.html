Failure Modes & Isolation Implications

The Tier III/Tier IV distinction (Uptime Institute) is exactly this: Tier III gives concurrent maintainability via dual paths with one active at a time, while Tier IV requires both paths to be simultaneously active and independently fault tolerant. Knowing which tier this site is built to changes what “safe to isolate one path” actually means in practice.
