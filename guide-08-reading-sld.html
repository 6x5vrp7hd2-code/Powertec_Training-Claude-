Section 08

Reading a Single Line Diagram

Single-line diagram (SLD/one-line) symbology is governed internationally by IEC 60617 (Graphical symbols for diagrams), while device tagging follows IEC 81346 (industrial

systems designation), superseding the older IEC 60617-2 tagging convention the guide mentions.

Additional context:

Symbol logic as a safety-critical skill. The guide’s “reading key” — that symbols combine additively (a switch-disconnector has both the isolating bar AND the on-load circle; a draw-out breaker adds chevrons) — reflects a deliberate design philosophy in IEC 60617: each mark represents one specific capability (visible break, on-load switching, short-circuit breaking, withdrawability), so a device’s full symbol is a visual sum of exactly what it can do. This is precisely why confusing symbols (mistaking a switch-disconnector’s circle for a breaker’s cross) is identified elsewhere in the guide (section 9.1) as a historical cause of serious accidents — the symbol IS the safety information.

ANSI vs IEC diagram conventions. North American practice frequently uses ANSI/IEEE device function numbers (the same numbering referenced in section 10.3 — e.g., 50/51 for overcurrent, 87 for differential protection) combined with different graphical conventions (rectangles or half-circles for breakers, rather than the IEC cross), which is exactly the “in-house diagram” hazard the guide warns about: a site’s actual legend must always be confirmed before any manoeuvre, since two visually similar drawings from different design traditions can mean structurally different things.

IEC 81346 tagging. This standard (which superseded parts of IEC 60617-2 for reference designations) structures equipment tags hierarchically by function letter and location, which is the basis for tags like “QF2-RECT” the guide describes — Q for a switching device function, F for a protective function, “2” as an instance number, and “RECT” as a plain-language location/function suffix particular to the site’s own convention.
