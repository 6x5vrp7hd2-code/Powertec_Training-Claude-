Scenario

A UPS is being brought back from maintenance bypass to normal running. Describe the sequence that avoids a period with no source at all.

Model Answer

Confirm the UPS is healthy and synchronised to bypass, close the UPS's own input/output breakers first, confirm the inverter is running and synchronised, then open the maintenance bypass breaker — output remains continuously live throughout because both paths briefly run in parallel before the bypass path is removed.

This is a model answer, not the only acceptable one — if your reasoning reaches the same operational conclusion by a different route, discuss it with a mentor rather than treating this as the sole correct wording.
