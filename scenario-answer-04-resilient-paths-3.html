Scenario

You are asked to confirm this site meets Tier III concurrent maintainability for one cell. What evidence would you need to see to confirm that, rather than assume it?

Model Answer

Evidence would include as-built SLDs showing genuinely independent A/B paths to separate sources, a completed capacity study confirming the surviving path can carry full load, commissioning records proving a live transfer under load, and confirmation that maintenance has previously been performed on one path without incident to the load.

This is a model answer, not the only acceptable one — if your reasoning reaches the same operational conclusion by a different route, discuss it with a mentor rather than treating this as the sole correct wording.
