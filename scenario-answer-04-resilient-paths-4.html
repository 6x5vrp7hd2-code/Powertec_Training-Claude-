Scenario Card 4 — Model Answer

Compare your reasoning against this model answer, then discuss any gaps with a mentor.

Scenario

During a planned path-A outage, load automatically transfers to path B. Path B's capacity was not confirmed beforehand. What is the risk, and how should this have been checked in advance?

Model Answer

If Path B lacks spare capacity, the transfer could overload its equipment, tripping protection and dropping the load entirely — the opposite of the intended resilience. Capacity should always be confirmed by calculation or test before relying on an automatic transfer, never assumed from design intent alone.

This is a model answer, not the only acceptable one — if your reasoning reaches the same operational conclusion by a different route, discuss it with a mentor rather than treating this as the sole correct wording.
